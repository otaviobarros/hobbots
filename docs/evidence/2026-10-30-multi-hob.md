## Gaps

- Claude Code keeps the system prompt a resumed session started with, so `systemPrompt.append` on a later turn is ignored. The fake runtime has no sessions, so the automated checks could not see this. Fixed by [#164](https://github.com/otaviobarros/hobbots/issues/164).
