# A hob with its own GitHub app works on GitHub as its bot, end to end against a fake GitHub

- **Date:** 2026-11-02
- **Issue:** [#228](https://github.com/otaviobarros/hobbots/issues/228)
- **Pull request:** not yet opened
- **Commit:** not yet on `main` (ran on the pull request branch, based on `d847d18`)
- **Setup:** Automated only. The hub is composed as `main.ts` composes it and driven over its HTTP API. The fake runtime makes the scripted GitHub Charm calls. A fake GitHub on a local port (`@hobbots/charms/testing`) serves the manifest flow, the app and installation endpoints, the REST API, the Git database API and Git over HTTP through `git http-backend`. The hub's own page, callback, token minting, push and API client talk to it; only their addresses change. The keychain is the in-memory one. The hob's sandbox is a stand-in that runs Git's `upload-pack` as it is and records the environment it gets. To stand in for an hour passing, the hub's wall clock and the fake GitHub's are moved ahead together, while sleeps stay real. Frodo gets its own app; Sam stays on the user's account. Linux x86_64, Node 22.23.4, Git 2.43, on SQLite in memory and on PostgreSQL 18. CI runs the suite on SQLite and PostgreSQL.
- **Result:** Passed with gaps. A hob given its own app from the hub's page commits locally as its bot. It pushes commits that GitHub made as the bot and marked Verified, and it opens a draft pull request and comments as the bot, while a hob without an app still acts as the user. Its token is replaced after its hour without asking. A revoked key or an uninstalled app fails clearly and never acts as the user. Disconnecting and retiring remove the key. No key, JWT or token appears anywhere a hob or client can read. An uninstalled app is not marked for reinstalling on its Charms tab ([#419](https://github.com/otaviobarros/hobbots/issues/419)), and real GitHub was not part of this run.

## Gaps

- No real GitHub. Whether GitHub accepts the loopback manifest, signs commits that an installation token makes through the Git database API, and shows them Verified is GitHub's documented behaviour as the fake serves it ([#420](https://github.com/otaviobarros/hobbots/issues/420)).
- An uninstalled app fails clearly but is not marked as needing a reconnect, because GitHub refuses to mint its token rather than refusing a token it minted ([#419](https://github.com/otaviobarros/hobbots/issues/419)).
- Only the fake runtime ran, so the local commit was made with the launcher's environment rather than inside a real Claude Code turn. The sandboxed commit is proven in `[TC-CH-197]` on macOS.
- The hob's sandbox was a stand-in that records the environment. The keychain was the in-memory one, so this run says nothing about the macOS Keychain or the Secret Service.
- The hour passed on the clocks, not in real time.
