- **Date:** 2026-11-09

- **Setup:** Apple M1 Pro, macOS 27.0.1, arm64. The app was packaged from `4cdce15` with `pnpm package`, ad hoc signed, and run by path with `--user-data-dir` under a scratch folder. It still reads 0.0.3, because the release pull request that sets 0.0.4 had not merged. Claude Code 2.1.316 with `haiku` at low effort, kept to a few turns. Codex 0.166.0 with `gpt-6-luna` at low effort, which ran most steps. Both used signed-in subscriptions on Balanced unless a row says otherwise. Git had no global name or email until section 6 set a throwaway one. No GitHub account was connected. The window was driven over its debugging port.
- **Result:** Passed with gaps. Every section ran on both runtimes. 17 findings are filed as issues for v0.0.5, and two more were reported privately.
