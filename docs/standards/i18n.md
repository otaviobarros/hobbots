# Internationalization standards

Hobbots will be translated. No i18n library is chosen yet, so these rules keep the code ready for one. When a library arrives, these rules change to name it.

### STD-I18N-001 User-facing copy lives in message modules

Put every user-facing string in a `messages.ts` module in the feature folder, under a stable key. Components read copy from that module and never hold literal user-facing strings.

- ✅ `<h2>{messages.profile.title}</h2>`
- ❌ `<h2>Hob profile</h2>`
- **Why:** adopting a library then means swapping one module per feature, not searching every component.
- **Enforced by:** review. Existing copy moves into message modules when its component next changes.
- **Applies to:** `apps/web`, `apps/desktop`, `packages/ui`.

### STD-I18N-002 Messages are whole sentences with placeholders

Write each message as a whole sentence with named placeholders. Never join fragments to build a sentence. Choose plural forms with `Intl.PluralRules`.

- ✅ `` summoned: ({ date }) => `Summoned ${date}` ``
- ❌ `"Summoned " + date + " by " + name`
- **Why:** word order and plural rules differ between languages, and a translator cannot reorder fragments.
- **Enforced by:** review.
- **Applies to:** message modules.

### STD-I18N-003 Dates and numbers use shared locale formatters

Format dates, times, relative times and numbers only through shared `Intl` formatters that take a locale. Components never call `toLocaleDateString` or build date text themselves.

- **Why:** one place then decides the locale and the format for every screen.
- **Enforced by:** review.
- **Applies to:** `apps/web`, `apps/desktop`, `packages/ui`.

### STD-I18N-004 Layout survives longer text and right-to-left scripts

Use logical CSS properties: `ms-`, `me-`, `ps-`, `pe-`, `start-` and `end-` in Tailwind, not `ml-`, `mr-`, `pl-`, `pr-`, `left-` and `right-`. Let text boxes grow with their content. Never put text inside an image.

- **Why:** translated text often runs longer than English, and right-to-left scripts mirror the layout.
- **Enforced by:** review.
- **Applies to:** `apps/web`, `packages/ui`.

### STD-I18N-005 Server and domain code return codes, not display text

Server, domain and adapter code returns error codes and data. Only the client turns them into text for the user.

- **Why:** the client knows the user's locale, and the server does not.
- **Enforced by:** review.
- **Applies to:** `apps/server`, `packages/*` except `packages/ui` and `packages/art`.
